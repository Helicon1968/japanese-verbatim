# 画面付きソースの補強（SKILL.md 手順5の詳細）


**音声で曖昧だった技術用語は、ほぼ必ず画面に映っている。**
焼き込み字幕も自動生成であることが多く、同種の誤りを含む。正解として扱わないこと。

### 5-1. 候補を出して読む

```bash
uv run --no-project --python 3.12 --with imageio-ffmpeg \
    python $SK/scripts/grab_frames.py <動画>
```

抜き出したフレームは `.jv/work/frames/` に入る（finish で消える）。
**1枚ずつ読んで内容を確かめる。** 用語の照合はここで済ませる。

**候補が多いときは、先に一覧表で選別する。**

```bash
uv run --no-project --python 3.12 --with pillow \
    python $SK/scripts/contact_sheet.py .jv/work/frames
```

`.jv/work/sheets/` に 5x4 の一覧が出る。各コマには時刻が焼き込んであるので、
そのまま `--at` に渡す値が読める。

実測では**60分を超える動画で候補が100枚近くになる**（68分で97枚）。
原寸で1枚ずつ開くと高くつくので、**縮小した一覧で「画面に文字があるか」を見て、
採る候補だけ原寸で確かめる**。縮小してもスライドか話者のアップかは判別できる。
判別できなかったものは原寸で開くこと。

**一覧にしても全枚数に目を通すことは変わらない。** 飛ばすための道具ではない。
手順5-4（素材が1本かどうか）の確認にも同じ一覧を使う。

### 5-2. 採用した画面を成果物に入れる

```bash
uv run --no-project --python 3.12 --with imageio-ffmpeg \
    python $SK/scripts/grab_frames.py <動画> \
        --at <秒,秒,…> --assets <名前> --crop-bottom 12
```

`<名前>.assets/` に入り、`raw.txt` 用の `[[IMAGE]]` 行と本文用の参照が出力される。
`[[IMAGE]]` を `raw.txt` に追記すれば、Web記事と同じ取りこぼし検査（ゲート2）が
動画でも効く。**説明の `〔〕` を埋めること。ゲート2は点数しか数えない。**

**`--assets` は `--at` を必須にしてある。** シーン検出が返すのは画面が切り替わった
瞬間であって、話者がその画面を説明している時刻ではない。候補をそのまま貼ると
図と本文が数十秒ずれる。自分で選んだ秒数を指定する。

### 5-3. 何を貼るか（選定基準）

**画面上の文字が情報そのものになっているフレームだけを貼る。**

| 貼る | 貼らない |
|---|---|
| 設定ファイル・コード | 話者のアップ |
| コマンド一覧・メニュー | 暗転・トランジション |
| ツールの出力・エラー | ブラウザのクロームだけ |
| 図解スライド（下記の但し書きを読むこと） | スクロールの途中・重複 |

実測では、62分の講演から検出された60枚のうち、画面上の文字が情報になっていたのは
6割ほどだった。**全部貼らない。** 十数枚に絞る。

**切り取りを使う。** 焼き込み字幕をそのまま貼ると、誤った字幕を根拠資料として
貼ることになる（「字幕を正解として扱わない」という規約に自分で反する）。
話者のワイプも情報ではない。`--crop-bottom` / `--crop-right` で落とす。
ただし**切りすぎは欠落である。** 右端を詰めると画面の情報まで切れることがあるので、
結果を目で見て確かめる。

#### 切り取り幅は一律にしない

**幅を1つ決めて全部に当てるとやられる。** 字幕は下端にあるが、
**スライドの下端に情報がある回がある**。実測した例。

| 画面 | 下端にあったもの | 使った幅 |
|---|---|---|
| 結論が赤字で最下行にあるスライド | 「変わったのは pre-norm だけ」という本文そのもの | **1%** |
| 字幕が2行になる回 | 字幕だけ | 14%〜18% |
| 題名と講演者だけ残したいスライド | 映画のスチルと論文の図 | **67%** |

手順は「**先に下端に何があるかを見てから幅を決める**」。候補を一覧して
（5-1）、下端に情報がある画面を洗い出し、**必要なら画面ごとに別の幅で抜き直す**。
`--at` は複数回に分けて実行できるので、幅の違う組を順に出せばよい。

**切り取りで落ちた情報は、本文に文字で補う。** 落としたまま貼らない。
実測では次の2つを補った。

- 最下部の数式（`Attention(Q,K,V) = softmax(QK^T/√d_k)V`）
- **画像の出典表記**（`CC-BY-SA by …`、`slide from …`）

**出典表記は字幕と同じ帯にあることが多い。** 切ると一緒に落ちる。
**表記を落としたまま貼るのは、出所不明の図を貼るのと同じである。**
落ちたら本文に書き写す。

#### 権利上の線引き

**判断は3段ある。** 「講演者が作ったか否か」だけでは足りない。
実際に多いのは、**講演者のスライドの中に他者の図や投稿が入っている**形である。

| 画面の中身 | 判断 |
|---|---|
| 設定ファイル、コマンド、ツールの出力 | **貼ってよい。**「その製品がそう表示する」という事実である |
| 講演者が作った文・一覧・図・コード | **貼ってよい**（下記の但し書きを読むこと） |
| 講演者の構成の中に他者の図・投稿が入る | **加工して貼る。** 切り取りで他者の部分を落とせるなら落とす。落とせないなら要旨に替える |
| 画面の全体が他者の成果物の複製（投稿のスクリーンショット等） | **貼らない。** 要旨を訳し、引用元を示す |
| 自分の録画、社内資料、自由なライセンスの動画 | 制約なし |

**切り取りは権利判断の道具でもある。** 実測では、題名・講演者・講義名だけを残して
下67%を落とし、映画のスチルと論文の図を外した。**出典を示すという目的には足りる。**

有料・無償の線引きも変わらない。**有料の講義でスライドを貼ると、成果物が
講義の代替物になる。** その場合は図の内容を文章と表に落とし、画面は設定・出力に限る。
無償公開の講義（大学の公開講義など）なら図解スライドも採ってよい。

**どちらに寄せたかは `<名前>.exempt.txt` に書く。** 判断そのものより、
判断の理由が後から要る。

### 5-4. 素材が1本かどうかを確かめる

**長い動画は、複数の素材のつなぎ合わせであることがある。**
気づかずに1本として書くと、**冒頭の出典欄が嘘になる**。訳や補足を正しく書いても、
出典が誤っていれば成果物として成立しない。

**実測**: 68分の動画が、対面の基調講演（〜22:09）＋別の講義の断片（〜24:26）＋
Stanford CS25 の講義（24:26〜）の3本だった。X から取得したもので、
つないだ順番は時系列ですらなかった（後半のほうが1か月早い）。

兆候は映像と音声の両方に出る。**どれか1つでも見つけたら疑う。**

| どこに出るか | 兆候 |
|---|---|
| **映像** | 画作りが変わる（対面撮影 ⇄ 画面共有、ワイプの有無、解像度感） |
| **映像** | **タイトルスライドが冒頭以外に出る**。これがいちばん確実 |
| **音声** | 司会の締めや拍手が途中に入る（「thank you so much」等） |
| **音声** | 自己紹介が2回出る。話者が変わる。音質・残響が変わる |
| **内容** | 同じ話題を2回立ち上げる。前半の結びのあとに新しい導入が来る |

確かめ方は2つで足りる。

- **シーン検出の候補を時系列で一覧して見る**（5-1）。画作りの変化は縮小しても分かる
- **文字起こしを締めの語で拾う**。`thank you` `applause` `so today` `let me introduce`

見つけたら、次の3つをやる。

1. **冒頭の出典欄に区切りを書く**（何分から何分が何なのか）
2. **判断の根拠を `<名前>.exempt.txt` に残す**。後から見て再確認できるようにする
3. **節構成を区間で分ける**。連続した1本のように並べない

**疑わしいが確定できないときは、確定できないと書く。** 素材の由来は推測で埋めない。
